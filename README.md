# 🕯️ EMBER Candle Shop

A modern, fully responsive e-commerce website for a handmade sculptural candle brand, built with **HTML**, **CSS**, and **JavaScript**.

EMBER Candle Shop combines a warm premium visual style with a product collection, interactive shopping cart, ritual gift set, and responsive checkout experience.

## 🛒 Shopping Cart

Customers can add candles and gift sets to their cart directly from the product collection.

The cart dynamically updates product quantities and calculates the total order value before checkout.

The checkout form collects customer information and allows customers to leave an optional comment with their order.

## 📲 Telegram Integration

Telegram order notifications are planned for a future update.

Order information will be sent securely through a backend endpoint so Telegram credentials are not exposed in the frontend.
